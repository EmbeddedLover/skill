# MRD 完整性检查清单

起草 PRD 前，确认 MRD 是否包含以下信息：

- 问题定义
- 目标用户
- 业务目标
- 成功指标
- 范围与非目标
- 约束条件
- 竞品或替代方案
- 核心场景
- 优先级或 MVP 边界
- 依赖项
- 风险
- 时间线或发布目标
- 必须保留的既有假设

只有当缺失信息会影响产品范围、实现优先级或验收标准时，才提出澄清问题。

默认高优先级问题：

1. 首要目标用户是谁？
2. 产品第一阶段必须解决的核心问题是什么？
3. 什么结果或指标代表成功？
4. MVP 范围是什么，哪些内容明确不做？
5. 是否存在截止日期、平台、预算、合规或技术栈等交付约束？

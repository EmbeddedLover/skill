# 工作流程

## 阶段 1：候选方案方向调研

1. 读取 PRD。
2. 提取：
   - 产品形态
   - 用户可感知核心能力
   - MVP 范围和非目标
   - 必需接口
   - 供电方式和功耗约束
   - 尺寸、结构、环境和认证约束
   - 目标成本或售价带
   - EVT/DVT/PVT 或上市阶段门槛
3. 使用 `category-checklists.md` 识别关键器件类别。
4. 对每个关键类别联网查证当前来源：
   - 国产候选
   - 国际候选
   - 成熟生态候选
   - 低成本候选
   - 快速 EVT 候选
5. 按以下维度比较候选方向：
   - 功能匹配度
   - 开发难度
   - 参考资料完整度
   - 价格区间
   - 采购可得性
   - 认证影响
   - 固件/软件生态
   - 供应风险
   - EVT、DVT 和量产适配性
6. 最终定稿前，要求用户确认一个方案方向。

## 阶段 2：最终硬件方案

用户确认方向后：

1. 联网查证具体型号和模块。
2. 收集：
   - 官方产品页或数据手册
   - 立创/LCSC 采购链接或搜索链接
   - 淘宝采购链接或搜索链接
   - 价格和查询日期
   - 页面可见的库存或可得性状态
   - 封装和关键电气/结构约束
   - 替代料/第二来源选项
3. 使用 `output-template.md` 生成一份整合版 Markdown 报告。
4. 除非用户指定其它路径，否则保存到 `docs/hardware/[product]-hardware-solution.md`。

## 自动选择

如果用户明确要求不要暂停，自动选择风险最低的方向，并清楚标注：

`自动选择：成熟均衡量产方案`

同时说明选择理由。

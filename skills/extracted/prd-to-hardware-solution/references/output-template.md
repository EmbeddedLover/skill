# 输出模板

最终输出是一份 Markdown 文档。

使用以下结构：

1. 方案摘要
2. 需求与假设
   - 用户已确认需求
   - 合理工程假设
   - PRD 约束来源
3. 候选方案比较
   - 国内候选
   - 国外候选
   - 成熟均衡方案
   - 国产低成本方案
   - 快速 EVT 打样方案
   - 高性能/高扩展方案，如适用
4. 用户确认的方案方向
5. 推荐系统框图
6. 数据流说明
7. 关键器件建议
8. 器件采购参考
   - 型号
   - 官方资料
   - 立创/LCSC 链接
   - 淘宝链接
   - 查询日期
   - 价格/库存证据
9. 接口与信号规划
10. MCU/SoC/核心芯片引脚分配
11. 电源树与功耗预算
12. BOM 成本估算
13. PCB 与结构约束
14. EMC / ESD / 安规注意事项
15. 风险清单
16. 验证计划
   - 原理图审查
   - PCB 审查
   - EVT 测试
   - DVT 测试
   - PVT/小批量测试，如适用
17. 待确认事项

## 图示

硬件工程师阅读时，系统框图优先使用文本块：

```text
PC / App
  |
USB / BLE / Wi-Fi
  |
MCU / SoC
  |-- Sensor
  |-- Display
  |-- Power
```

## 价格格式

价格波动时使用区间：

| 器件型号 | 功能 | 单价范围 | 数量 | 小计 | 证据 |
|---|---|---:|---:|---:|---|

估算必须清楚标注为 `估算`，不要写成采购报价。

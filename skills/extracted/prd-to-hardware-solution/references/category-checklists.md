# 品类器件清单

使用本文件根据 PRD 识别可能需要评估的器件类别。

## USB 外设 / 小键盘 / 宏键盘

- 支持 USB Device 的 MCU
- 显示器件：OLED/LCD/TFT/电子纸
- 按键、轴体、编码器、热插拔轴座
- USB-C 连接器
- ESD/TVS 防护
- LDO 或 DC/DC
- 如需要，晶振或有源时钟
- 存储：片内 Flash / EEPROM / 外部 Flash
- 状态 LED / RGB LED
- 调试接口：SWD/JTAG/UART
- 外壳和结构件

## 无线音频 / 麦克风接收器

- 麦克风咪头
- 无线音频 SoC / RF 收发器
- 音频 Codec / ADC / DAC
- MCU / 应用处理器
- 电池
- 充电芯片 / PMIC
- USB-C / Lightning / 3.5 mm / 冷靴接口
- 天线和 RF 匹配
- 如有内录功能，加入存储器
- 按键、LED、显示屏
- ESD/EMI 防护

## 可穿戴 / 智能手环

- MCU / 可穿戴 SoC
- PPG 心率传感器
- IMU
- 显示屏
- 电池
- 充电芯片 / PMIC
- BLE 射频或集成 SoC
- 振动马达
- 触摸或按键
- 防水连接器或充电触点
- 皮肤接触材料
- ESD/EMI 防护

## IoT 传感设备

- MCU / 无线 SoC
- 主传感器
- 辅助传感器
- 电源和 PMIC
- 无线：BLE/Wi-Fi/LoRa/NB-IoT/蜂窝网络
- 天线
- 存储
- 外壳和环境防护
- 调试/烧录连接器
- ESD/EMI 防护

## 电机控制 / FOC 驱动板

- 电机控制 MCU，或带高级定时器、ADC、比较器/运放资源的 MCU
- 三相栅极驱动器，或集成三相 BLDC/PMSM 驱动器
- 如驱动器未集成，加入功率 MOSFET
- 电流采样：采样电阻、电流采样放大器、集成电流采样或相电流/母线电流采样
- 母线电压采样和温度采样
- 电机反馈：霍尔、ABZ 编码器、磁编码器、SPI/I2C 编码器或无感方案
- 电源输入保护：保险丝/自恢复保险丝、反接保护、TVS、浪涌/上电冲击处理
- 电源轨：电机驱动、MCU、传感器和接口电路所需 DC/DC 与 LDO
- 通信/调试：USB-C、USB-UART、SWD/JTAG、CAN、UART、PWM、I2C/SPI
- 用户指示和控制：电源/运行/故障 LED、复位/BOOT/用户按键
- 与目标电压/电流匹配的电机端子和电源端子
- USB、编码器、霍尔、通信和电源接口的 ESD/EMI 防护
- 热设计：铺铜面积、导热过孔、散热片或风道约束
- 测试与工厂治具：烧录、三相输出检查、电流采样检查、反馈输入检查
- 面向学习者的文档与安全标签：接线、极性、电压/电流上限、常见故障状态

## 通用选型维度

每个关键器件都按以下维度评估：

- 功能匹配度
- 电压/电流匹配度
- 接口兼容性
- 封装和 PCB 难度
- 固件/软件生态
- 文档完整度
- 样品可得性
- 立创/LCSC 可得性
- 淘宝可得性
- 价格区间
- 第二来源可得性
- 认证影响
- 生命周期和供应风险
- EVT 适配性
- 量产适配性

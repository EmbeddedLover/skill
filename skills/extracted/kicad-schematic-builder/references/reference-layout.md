# 内置模块化原理图参考说明

## 何时读取

仅在新建、重新布局、用户明确要求内置风格，或当前任务没有提供布局参考时读取 `../assets/reference-modular-schematic.png`。只读审计、ERC 修复、符号来源检查和局部网络修改不需要加载该图片。

存在当前上传图片时，以用户文字和当前图片为准；使用任何参考图进行设计前，输出 `继承 / 调整 / 忽略` 清单。

## 可继承的视觉策略

- A4 横向单页结构；
- 大矩形功能模块分区；
- 主控位于页面中部或中下部并占据主要面积；
- 电源和外围模块沿页面顶部排列；
- 调试、通信或下载模块位于左侧；
- LED、按键和扩展接口位于右侧；
- 安装孔位于页面底部独立区域；
- 每个模块使用醒目的中文标题；
- 模块内使用短线，模块间优先使用网络标签；
- 器件、标签和说明文字按网格整齐排列；
- 右下角保留标题栏区域。

## 必须按当前项目调整的内容

- 主控型号、引脚数量和封装；
- 模块数量与页面占比；
- 电源轨和稳压方案；
- 时钟、复位、启动和调试接口；
- GPIO 排针数量和 pin map；
- 说明文字、项目标题和版本；
- KiCad 与参考图原 EDA 工具之间的符号风格差异。

## 默认忽略的参考图电路

除非用户当前明确要求，否则不要复制：

- USB-C 接口；
- CH340 串口；
- OLED 接口；
- 三色或多路 LED；
- ESP32 自动下载电路；
- ESP32-WROOM 模组和其专用网络；
- 参考图中的具体日期、项目名称和嘉立创EDA标题栏内容。

## 参考图的用途边界

这张图片主要用于约束页面结构、模块关系、视觉密度、标题风格和局部布线方式。它不是权威原理图，不能用于推断当前项目未说明的电气连接、器件参数或接口定义。

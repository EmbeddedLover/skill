# 覆盖率与验证

覆盖率和测试结果是证据，不是承诺。

## 结果措辞

使用：

- `已生成，未执行`
- `仅生成骨架，断言待补充`
- `已执行，失败`
- `已执行，通过`
- `结果不明确`
- `覆盖率未采集`
- `覆盖率由工具报告为 X%`

不要使用：

- `已验证全部功能`
- `硬件验证通过`
- `无风险`
- `覆盖完整`
- `回归已关闭`

除非有直接证据，并且范围边界非常清楚。

## 覆盖率解释

Line 或 branch coverage 不证明：

- 硬件时序正确
- 中断顺序正确
- 电气兼容
- 不存在竞态
- 需求完整

覆盖率适合发现遗漏路径。应与测试矩阵和未解决风险列表一起使用。

## 最小最终摘要

完成单元测试生成任务时，包含：

- 已生成或建议的文件
- 选择的框架和原因
- 已生成用例
- 仍待确认的用例
- 测试是否已执行
- 已知硬件或集成缺口
